Privacy Policy for ArchiveComicsTV

Last updated: November 5, 2026

Who

ArchiveComicsTV is a private internal tool operated by Leonid Bugaev. It is used only by its owner.

What it does

ArchiveComicsTV uploads videos, sets thumbnails, posts comments and reads analytics on the owner's own YouTube channels (Archive Comics TV and related channels). It does this through the YouTube Data API and the YouTube Analytics API.

Google user data accessed

The app accesses only the owner's own YouTube channel data and analytics, under the OAuth scopes the owner grants. It does not collect data from any other users.

How the data is used

The data is used only to perform those actions for the owner: uploading videos, setting thumbnails, posting comments and reading analytics on the owner's channels.

Sharing

ArchiveComicsTV does not sell, share or transfer Google user data to third parties. It does not use the data for advertising.

Storage and security

OAuth tokens are stored locally on the owner's own machines. The app does not keep Google user data on external servers.

Retention and deletion

The owner can delete the local tokens at any time. Access can also be revoked at https://myaccount.google.com/permissions.

Google API Services Limited Use

ArchiveComicsTV's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

YouTube API Services

Use of ArchiveComicsTV is also subject to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.
